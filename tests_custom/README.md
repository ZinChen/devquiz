# Локальные тесты

Файлы `*.yml` из этой папки читаются приложением наравне с `../tests/`, но
не трекаются гитом — в репозиторий попадает только этот README.

Зачем: проходить свои тесты локально **с сохранением статистики**. В отличие от
перетаскивания файла на список тестов (разовое прохождение, попытки не пишутся),
тесты отсюда — полноценные: попытки, история в кабинете, слабые темы, закладки.

## Как пользоваться

1. Положите сюда `my-test.yml` в том же формате, что и файлы в `../tests/`.
2. Перезапустите Rails (синхронизация идёт на старте) либо выполните
   `bundle exec rails yaml_sync:sync_all` из папки `app/`.
3. Тест появится в списке с меткой «Локальный».

**Имя файла должно совпадать со `slug:` внутри** — по имени файла ищутся вопросы.

Если слаг совпадёт с тестом из `../tests/`, победит файл отсюда, а на карточке
появится метка «Подменяет». Статистика при этом общая: слаг-то один.

## Что важно знать

- Папки нет у коллег и на сервере, поэтому там эти тесты просто не появятся.
- Если удалить файл, тест пропадёт из списка, но попытки в БД останутся: вернёте
  файл — вернётся и история.
